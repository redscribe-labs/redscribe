Permanently delete engagement?

This permanently and irreversibly destroys "{{ engagement.client_name }}" and everything under it — findings, checklist runs, comments, scope-change history, and its encryption key — from the live database. This is not the same as archiving: there is no undo.

⚠ This does not remove the data from existing backups

A create_backup snapshot taken before this deletion, or a restore_backup pre-restore safety snapshot, still contains this engagement's data until it's separately pruned or overwritten. Routine backups age out after BACKUP_RETENTION_DAYS (30 days by default); pre-restore safety snapshots aren't auto-pruned at all. If a retention or disposal obligation requires this data gone from every copy, that means cleaning up backups taken before this point too — see Backup & restore.

Existing audit log entries referencing this engagement are kept — only the engagement's own data is removed. Intended for satisfying a data-retention policy on engagements that are no longer needed, not routine cleanup.
